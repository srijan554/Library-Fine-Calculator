# Library-Fine-Calculator
The Library Fine Calculator is a Java-based program designed to manage book records and calculate fines for books returned late. The program takes user input for book ID, book name, and the number of late days. It automatically calculates the fine at a rate of ₹5 per day.

The project uses the following concepts:
1. Array: Stores book IDs, names, late days, and fine amounts.
2. Searching: Uses Linear Search to find a book using its unique ID.
3. Sorting: Uses Bubble Sort to arrange book records in ascending order of book IDs.
4. Fine Calculation: Calculates the total fine based on the number of late days.
Objective: To develop a simple library management program that demonstrates the practical implementation of arrays, searching, and sorting algorithms using Java.

Technology Used: Java Programming Language.

Algorithms Used: Linear Search and Bubble Sort
